# Автоигра Block Blast

Бот играет в Block Blast на айфоне через «Видеоповтор iPhone» на Маке. Он снимает окно, распознаёт поле 8×8 и три фигуры,
перебирает все порядки и позиции фигур и выбирает лучший ход. Оценка учитывает снесённые линии, комбо, дырки и место под крупные фигуры (3×3, 1×5).
Потом бот перетаскивает фигуру мышью.

## Установка (один раз)
    python3 -m venv ~/bb-venv && ~/bb-venv/bin/pip install -U pip && ~/bb-venv/bin/pip install pyobjc-framework-Quartz numpy pillow

Терминалу нужны права «Запись экрана» и «Универсальный доступ» (Системные настройки → Конфиденциальность).

## Запуск
Открой «Видеоповтор iPhone», запусти игру и выполни в Терминале:

    ~/bb-venv/bin/python ~/gerda-script/blockblast/bot.py

- `--dry`: только показать распознанное поле и план, без ходов.
- `--moves N`: сделать не больше N ходов.

Остановить бота можно тремя способами: дёрнуть мышку, нажать Ctrl+C в Терминале или выполнить `touch /tmp/bb/stop`.
